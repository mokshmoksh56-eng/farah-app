# نظام وصلني كاش / إقبض 💸

تطبيق ويب متكامل يهدف إلى تسهيل عمليات طلب وتسليم السيولة النقدية (الكاش) بين العملاء والتجار، مع لوحة تحكم شاملة للإدارة.

## مميزات المشروع 🌟
* **واجهة العميل:** طلب كاش فوري، اختيار نوع السيولة (فودافون كاش أو إنستاباي)، وتحديد الموقع جغرافياً عبر الخريطة.
* **واجهة التاجر:** استقبال الطلبات في الوقت الفعلي، إدارة الرصيد، ومتابعة سجل العمليات.
* **لوحة الإدارة:** تحكم كامل في حسابات المتاجر والعملاء، متابعة الإحصائيات، ومراقبة سجل العمليات الشامل.
* **الخرائط:** دمج خرائط Mapbox لتحديد المواقع بدقة وحساب المسافات.

## التقنيات المستخدمة 🛠️
* **الواجهة الأمامية (Frontend):** HTML, Tailwind CSS
* **قاعدة البيانات والمصادقة (Backend):** Firebase Realtime Database & Firebase Auth
* **الخرائط وتحديد المواقع:** Leaflet.js & Mapbox API

## هيكل الملفات الرئيسية 📂
* `wslnycash.html`: التطبيق الرئيسي لدخول العملاء والتجار.
* `edaracash.html`: لوحة تحكم الإدارة الشاملة.
